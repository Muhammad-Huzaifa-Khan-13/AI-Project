# Intelligent Reading Comprehension and Quiz Generation System

## Objective
Build an AI-powered reading comprehension system using the RACE dataset.

## Core Requirements
- Traditional ML models
- Logistic Regression
- SVM
- KMeans clustering
- Distractor generation
- Hint generation
- Streamlit UI

## Dataset
RACE Dataset from Kaggle.

Columns:
- article
- question
- A
- B
- C
- D
- answer

## Model A
Question answering and verification.

## Model B
Distractor and hint generation.

## UI
Use Streamlit with 4 screens:
1. Article input
2. Quiz interface
3. Hint panel
4. Analytics dashboard

## Constraints
- No heavy GPU training
- Keep models lightweight
- Prefer traditional ML

Project initialized.
